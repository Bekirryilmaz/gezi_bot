Verilen sayfa URL’i için teknik SEO kontrol listesini döndür. `seo-audit` skill’ini ve `plan/02_seo_mimarisi.md` şablonlarını kullan.

Kontrol et:

- title (benzersiz, şablon uyumu)
- meta description (benzersiz)
- canonical
- robots (index/noindex)
- Open Graph / Twitter kartları
- JSON-LD (`application/ld+json`; `AggregateRating` YASAK)
- görünür breadcrumb + BreadcrumbList
- görsel `alt` (Türkçe, anlamlı)
- sitemap kaydı (gerekirse)

Her madde: geçti / eksik / ihlal + kısa kanıt (HTML parçası veya HTTP başlığı). Sonunda öncelikli aksiyon listesi yaz.

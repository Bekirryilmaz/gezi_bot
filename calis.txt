Samandira (Alegre Group) — Calistirma Rehberi
=============================================

Bu proje iki servisle ayaga kalkar: FastAPI (sunucu) + Next.js (site).
Ikisi de PostgreSQL'e bagli calisir. Marka: Samandira. Repo: gezi_bot.

ONKOSUL: PostgreSQL
-------------------
Bu makinede yerel PostgreSQL kullanilir (Docker yok). altyapi/ compose
yalniz baska ortamlar icin; burada C:\PostgreSQL gecerli.

  # Durum kontrol
  C:\PostgreSQL\bin\pg_ctl.exe status -D C:\PostgreSQL\data

  # Baslat (gerekirse)
  C:\PostgreSQL\bin\pg_ctl.exe start -D C:\PostgreSQL\data -l C:\PostgreSQL\data\startup.log -w

  # Durdur
  C:\PostgreSQL\bin\pg_ctl.exe stop -D C:\PostgreSQL\data -m fast

Baglanti (sunucu/.env veya varsayilan):
  postgresql+psycopg://gezi_kullanici:gezi_sifre@localhost:5432/gezi_veritabani

  sunucu/.env yoksa:
  copy sunucu\.env.example sunucu\.env

Python venv: repo kokunde .venv_test (veri + sunucu ayni venv).


Ilk kurulum (bir kez)
---------------------
Repo kokunden (gezi_bot\):

  python -m venv .venv_test
  .\.venv_test\Scripts\python.exe -m pip install -r sunucu\requirements.txt
  .\.venv_test\Scripts\python.exe -m pip install -r veri\requirements.txt
  .\.venv_test\Scripts\python.exe -m playwright install chromium

  cd sunucu
  ..\.venv_test\Scripts\python.exe -m alembic upgrade head

  cd ..
  .\.venv_test\Scripts\python.exe -m sunucu.veritabani.aktarim.calistir --sehir samsun

  cd site
  npm install

site\.env.local icinde API adresi olmali (yoksa olustur):
  NEXT_PUBLIC_API_URL=http://127.0.0.1:8125


1) API (FastAPI) — port 8125
----------------------------
Repo kokunden (gezi_bot\):

  .\.venv_test\Scripts\python.exe -m uvicorn sunucu.api.uygulama:uygulama --host 127.0.0.1 --port 8125

Swagger: http://127.0.0.1:8125/docs


2) Site (Next.js) — port 3000
-----------------------------
Baska bir terminalde:

  cd site
  npm run dev -- --port 3000

Tarayici: http://localhost:3000

Notlar
------
- Migrasyon her zaman sunucu\ icinden: ..\.venv_test\Scripts\python.exe -m alembic upgrade head
- Aktarim ve uvicorn her zaman repo kokunden.
- CORS icin sunucunun localhost:3000'e izin vermesi gerekir (API_IZINLI_ORIGINLER).
- Port doluysa: netstat -ano | findstr ":8125 :3000 :5432"
